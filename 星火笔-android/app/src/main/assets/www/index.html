📖 教程

    

      

        
        
        
        
        
        
        
        
        
      

      

        
⏱ 5 分钟跑通第一本

        
星火笔是「主AI决断 + 角色推理 + 正文写作 + 审查」的多Agent写作软件，你想当导演，AI 分工当编剧/演员/写手。三步跑通：

        
① 项目页 → 新建项目（填书名/剧情/世界观/规则），或「✨ 一键成书」（可勾选 AI 自动判断章节数）让 AI 自动立项连写，或「📥 小说导入成项目」把已有 txt 还原成项目。

        
② 写作页 → 填临场指示（可留空）→ 生成草稿 → 满意点「通过并完成」归档，不满意「凭意见重新生成」。

        
③ 去AI味 → 选正文一键洗稿（清 AI 腔/套话），处理后「应用」合并；文风校对工坊可多轮迭代贴近参考原文。

        
之后可全自动连写、AI 对话、拆书学技法、重写此章（世界状态回滚到该章前）…

      

      

        
✍️ 写作

        
逐章生成：主AI决断本章出场与场景 → 正文AI代入角色写 → 审查AI校验招式/行为/文风/禁词。

        
通过并完成：归档并自动更新角色信息库/伏笔/主AI笔记，留世界快照（重写可回滚）。

        
全自动生成：审过一章自动写下一章，到卷目标或你停止（停止立即生效，已归档保留）；生成前可开「剧情点确认」先改主AI的本章剧情点。

        
码字工作台：AI 续写 / 段落工具（润色·扩写·缩写·去AI味，上下文可勾选「故事设定+主AI笔记」）/ 语音码字 / 草稿箱 / 全文搜索 / 写作统计 / 章节交换。

        
小提示：章末留悬疑钩子；写后校对（正文完稿后主AI验收前）按文风/自定义规则校对，可单独开关。

      

      

        
👥 角色

        
每个角色一张卡（人设/目标/恐惧/说话风格/背景/关系）+ 独立信息库（主AI按章节记录处境/经历/秘密——只有主AI读，正文AI只读卡片，防剧透）。

        
建角色：手动填写生成 / 批量建档 / 主AI写作中自动建 / 酒馆 chara_card_v2 卡互换 / AI 分类。

        
角色卡不会被直接删除：删除章节 / 回滚世界后移出当前剧情的角色，不删盘而是进「♻ 废弃角色库」（附废弃原因与章节号，可随时「恢复」在籍或彻底删除）；主AI清理或手动归档的进「已归档」，两者都不参与演出。主AI若重新把某角色引入剧情，会自动恢复在籍。

        
小提示：卡里写清「读者对 TA 的第一印象」，角色推理才准；「一键核心角色团」一次建好当前剧情主要角色。

      

      

        
📁 项目

        
书架：多项目并存，点选切换；删除会连目录移除（谨慎）。设定锚点把关键设定钉住防遗忘；导出/导入项目 zip 换设备继续写。

        
✨ 一键成书：描述想写什么 + 全书总章节（或勾选 AI 自动判断章节数）→ AI 自动起名/立设定/建项目/生角色/连写。随时可停止（立即中断），停止后项目已建好。

        
📥 小说导入成项目：把已有 txt（未完成的小说尤其合适）还原成完整项目：自动拆书 → 合成世界观/文风/设定 → 按章节梳理人物与状态 → 建角色卡 → 章节原样入库 → 管理笔记与写作计划。删除章节后角色卡自动回退；断点续传。在「小说规划」栏把剧情设计/方向/主题/已有情节到哪告诉 AI，逐章分析人物不会跑偏。

      

      

        
💬 AI 对话

        
对话页（LM Studio 式）：API 连通性测试 / 聊设定 / 聊灵感。

        
话题：多话题记录，新建即可命名，可改名/删除/搜索；没开话题直接发送会自动建。

        
开关：「读当前项目（不含正文）」注入项目设定（不勾选 AI 完全读不到项目）；「🌐 联网搜索」发送前自动检索注入参考。

        
消息操作（作用于最后一条）：✏️ 编辑（改用户消息后自动重生成）/ 🔄 重生成 / ▶ 继续 / 🗑 删除；⏹ 停止立即断流；📤 导出整场对话 md。

      

      

        
🎨 文风校对工坊

        
A(提取文风)→B(生成文章)→C(评估打分)→D(优化提示词) 多轮迭代，直到相似度达标或到最大轮次；失败/暂停可「继续」续跑。预设库选「文风提取」「剧情设计提取」一键应用（两套正式版已内置，全新安装即有）。

        
文风提取=提炼语言质感/叙事视角/描写习惯；剧情设计提取=提炼节奏/钩子/冲突配比/事件拆解等设计技法。均禁止照抄具体情节。

        
以下为两套正式版提示词（node_a）与配套泛化模板——泛化模板用于把任意具体题材/平台的提示词转成通用技巧版（去题材/去时代/防照抄）：

        
文风提取（正式版）
节点构成：node_a 1712 字 / node_b 122 字 / node_c 190 字 / node_d 250 字 — 绑定在文风校对页预设下拉，选中后一键应用。
你现在是一位专业的小说写作风格分析师和角色卡设计师。
我提供了一篇小说范文（体裁不限）。
你的任务是：
仔细阅读范文，只提取写作风格特征，完全忽略具体人物姓名、背景设定、具体情节线索和事件发展（提取出的文风提示词禁止出现范文中的人物姓名等内容）。
重点总结以下通用文学风格维度（必须详细、具体、可操作）：

① 导入 txt（自动分卷分章，按卷分批，维系整体性）→ ② 调 token 预算/并行/大方向提示词 → ③ 开始（可停止，自动续传）。

        
风格库：拆完保存为风格；给当前项目应用后，主AI在决断/校验/审查时参考该设计技法。风格可导入导出分享。

        
拆书调用量大，建议在设置页给「拆书工坊/小说导入成项目」单独选便宜快的模型。

      

      

        
📖 档案 · 情景卡

        
故事档案 = 主AI的账本，分 6 个中页签：

        
① 伏笔台账：谁埋的、埋在哪章、到期没回收会标 ⚠逾期；② 时间线：已写章节按卷分组，点章节可阅读 / 归卷 / 交换 / 重写此章（重写会把世界状态回滚到该章前）。

        
③ 主AI管理笔记：主AI自己的剧情笔记；④ 主AI知识库：长期记忆（联网灵感、重要设定、关键伏笔），只有主AI读、正文AI看不到。

        
⑤ 生成日志：每章生成过程的记录；⑥ 分支存档：把「进度 + 世界状态」整体存一个存档点，想试不同走向先存档，走歪了载回即可。

        
情景提示词（左侧导航最后一页）= 情景规则卡：一类场景/桥段的写法规则（秘境夺宝、酒馆打探、宗门大比…）。

          · 总库：所有卡的家，可手动新增 / ✨AI 一键生成 / 📄从文本提取；

          · 本项目可用卡：只有在这里「＋ 从总库加入」的卡，本项目主AI才会用（主AI每章按正文类型挑 1~3 张注入正文AI；没匹配卡时它会自做一张只进本项目库）；

          · 提取提示词：改「从文本提取」的规则，改坏可一键恢复初始。

        
小提示：卡里写「怎么做」而不是「写什么」——只借写法、不搬情节，跨书通用才不串味。

      

      

        
⚙️ 设置与 API

        
API 配置：多套地址/Key/模型保存切换；用途分工——主AI决断/正文写作/角色推理/去AI味/审查AI/码字AI/拆书工坊/小说导入成项目/情景提示词制作/文风校对四节点（A提取·B生成·C评分·D优化）/AI 对话 共 14 个环节各选一个配置，还能给每个环节单独设「思考」强度（跟随全局/关闭/低/中/高/最大；JSON 环节设「关闭/低」明显提速）。不指定的跟随通用配置。

        
生成参数：温度 / 每章目标字数 / 正文上下限字数 / max_tokens / 角色推理方式（串行稳、并行快）/ 推理并发 / 重试 / 限流等待 / 压缩间隔 / 思考强度等；码字AI 的三个「任务上下文」开关（正文AI提示词与文风 / 主AI笔记 / 角色推理）在这里统一控制。

        
联网搜索灵感 / 审查不过自动重写 / 写后校对 / 生成前确认剧情点：按喜好开关。

        
界面风格：设置页四选一 🌸樱粉软萌（默认）/🌿薄荷奶油/🌙二次元夜/🌒静谧石墨（深色·低亮护眼，长时间码字不刺眼），切换立即生效并记住；界面与电脑端同一套布局（左侧导航 + 右侧工作区），默认横屏启动、可切竖屏，窄屏时导航收窄为图标栏。

        
界面缩放：设置页「界面缩放」或导航底部 −/＋（点百分比恢复 100%，50%~160%，同电脑端范围），也可双指捏合缩放页面——屏幕小的机器调小一点能一屏看更多。
