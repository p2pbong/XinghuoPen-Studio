📖 教程

      

        
        
        
        
        
        
        
        
      

      

        
⏱ 5 分钟跑通第一本

        
星火笔是「主AI决断 + 角色推理 + 正文写作 + 审查」的多Agent写作软件，你想当导演，AI 分工当编剧/演员/写手。三步跑通：

        
① 项目页 → 新建项目（填书名/剧情/世界观/规则），或「✨ 一键成书」（可勾选 AI 自动判断章节数）让 AI 自动立项连写，或「📥 小说导入成项目」把已有 txt 还原成项目。

        
② 写作页 → 填临场指示（可留空）→ 生成草稿 → 满意点「通过并完成」归档，不满意「凭意见重新生成」。

        
③ 去AI味 → 选正文一键洗稿（清 AI 腔/套话），处理后「应用」合并；文风校对工坊可多轮迭代贴近参考原文。

        
之后可全自动连写、AI 对话、拆书学技法、重写此章（世界状态回滚到该章前）…

      

      

        
✍️ 写作

        
逐章生成：主AI决断本章出场与场景 → 正文AI代入角色写 → 审查AI校验招式/行为/文风/禁词。

        
通过并完成：归档并自动更新角色信息库/伏笔/主AI笔记，留世界快照（重写可回滚）。

        
全自动生成：审过一章自动写下一章，到卷目标或你停止（停止立即生效，已归档保留）；生成前可开「剧情点确认」先改主AI的本章剧情点。

        
码字工作台：AI 续写 / 段落工具（润色·扩写·缩写·去AI味，上下文可勾选「故事设定+主AI笔记」）/ 语音码字 / 草稿箱 / 全文搜索 / 写作统计 / 章节交换。

        
小提示：章末留悬疑钩子；写后校对（正文完稿后主AI验收前）按文风/自定义规则校对，可单独开关。

      

      

        
👥 角色

        
每个角色一张卡（人设/目标/恐惧/说话风格/背景/关系）+ 独立信息库（主AI按章节记录处境/经历/秘密——只有主AI读，正文AI只读卡片，防剧透）。

        
建角色：手动填写生成 / 批量建档 / 主AI写作中自动建 / 酒馆 chara_card_v2 卡互换 / AI 分类。

        
小提示：卡里写清「读者对 TA 的第一印象」，角色推理才准；「一键核心角色团」一次建好当前剧情主要角色。

      

      

        
📁 项目

        
书架：多项目并存，点选切换；删除会连目录移除（谨慎）。设定锚点把关键设定钉住防遗忘；导出/导入项目 zip 换设备继续写。

        
✨ 一键成书：描述想写什么 + 全书总章节（或勾选 AI 自动判断章节数）→ AI 自动起名/立设定/建项目/生角色/连写。随时可停止（立即中断），停止后项目已建好。

        
📥 小说导入成项目：把已有 txt（未完成的小说尤其合适）还原成完整项目：自动拆书 → 合成世界观/文风/设定 → 按章节梳理人物与状态 → 建角色卡 → 章节原样入库 → 管理笔记与写作计划。删除章节后角色卡自动回退；断点续传。在「小说规划」栏把剧情设计/方向/主题/已有情节到哪告诉 AI，逐章分析人物不会跑偏。

      

      

        
💬 AI 对话

        
对话页（LM Studio 式）：API 连通性测试 / 聊设定 / 聊灵感。

        
话题：多话题记录，新建即可命名，可改名/删除/搜索；没开话题直接发送会自动建。

        
开关：「读当前项目（不含正文）」注入项目设定（不勾选 AI 完全读不到项目）；「🌐 联网搜索」发送前自动检索注入参考。

        
消息操作（作用于最后一条）：✏️ 编辑（改用户消息后自动重生成）/ 🔄 重生成 / ▶ 继续 / 🗑 删除；⏹ 停止立即断流；📤 导出整场对话 md。

      

      

        
🎨 文风校对工坊

        
A(提取文风)→B(生成文章)→C(评估打分)→D(优化提示词) 多轮迭代，直到相似度达标或到最大轮次；失败/暂停可「继续」续跑。预设库选「文风提取」「剧情设计提取」一键应用（两套正式版已内置，全新安装即有）。

        
文风提取=提炼语言质感/叙事视角/描写习惯；剧情设计提取=提炼节奏/钩子/冲突配比/事件拆解等设计技法。均禁止照抄具体情节。

你的任务是：
仔细阅读范文，只提取写作风格特征，完全忽略具体人物姓名、背景设定、具体情节线索和事件发展（提取出的文风提示词禁止出现范文中的人物姓名等内容）。
重点总结以下通用文学风格维度（必须详细、具体、可操作）：
- 语言质感与用词习惯：词汇的雅俗偏好（如：古风雅致、现代冷峻、口语化、书面语等），常用的高频形容词、动词及特定领域的术语；句式的长短节奏控制。
- 叙事视角与声音：叙述者的口吻（冷静旁观、深情沉浸、幽默调侃、压抑克制等），人称选择及其对读者代入感的影响，内心独白与外部描写的比例。
- 修辞与意象系统：最常用的比喻类型（明喻/暗喻/通感），核心意象群（如：自然景物、机械冷硬、色彩光影等），以及如何处理抽象情感的具体化表达。
- 环境与氛围营造：如何通过环境描写烘托情绪（情景交融的手法），对光线、声音、气味、温度等感官细节的侧重优先级及融合方式。
- **行文节奏与呼吸感**：长短句交错的阅读律动，标点符号对语速的精准牵引（如破折号制造悬停、句号切割张力、省略号延宕情绪），段落切分的视觉节奏，以及叙事推进中“慢镜头”铺陈与冲突爆发时“快切”处理之间的动态切换。
- 节奏与结构技巧：场景切换的方式（蒙太奇/线性推进），对话与动作描写的配比，高潮或转折点的情绪爆发力构建手法，留白与详述的艺术。
- 人物塑造风格：如何通过侧面描写、微表情、潜台词展现角色性格，而非直接陈述；角色互动的张力来源（权力关系、情感流动等）。
- 整体基调与美学风格：是华丽繁复、极简冷淡、荒诞黑色、还是温暖治愈？语调的情感浓度如何控制？

核心写作风格锚定（必须100%严格遵守）：
用词偏好：偏爱冷静、克制且具象化的动词与名词，少用过度修饰的形容词。常用“灰暗”、“潮湿”、“疏离”、“破碎”等带有情绪色彩的词汇，句式多为短句，节奏紧凑有力。

修辞手法：大量使用通感和隐喻，将抽象情绪转化为具体的物理感受（例如：“焦虑像蚂蚁在皮肤下爬行”）。避免直白的心理陈述，倾向于通过动作细节和环境反射来暗示心理状态。
环境氛围：注重“情景交融”，环境不仅是背景，更是情绪的延伸。擅长描写阴雨天、昏暗灯光、嘈杂后的寂静等具有压迫感或孤独感的场景，调动视觉、听觉与触觉的多重感官体验。
行文节奏控制：严格复刻范文的句式呼吸感与段落切割节奏。平缓叙事期采用绵密长句营造沉浸式流淌感；情绪对峙或动作发生期使用短促断句制造紧迫感与顿挫力；标点使用需精准牵引阅读停顿（如用句号切断张力，用破折号延宕余韵）。

必须通过“展示而非告知（Show, Don't Tell）”的手法展现人物性格与内心波动。
每段描写需融合至少两种感官细节，并服务于当前场景的情绪基调。
**行文节奏执行**：生成内容时必须严格遵循提炼出的长短句交替律动与段落切分习惯，避免平铺直叙的单一语速；在情绪蓄势阶段拉长句式与段落密度，在爆发节点使用短句与留白制造冲击力。
